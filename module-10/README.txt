CSD402 - Module 10.2

Compile all four files from this folder:
  javac Division.java InternationalDivision.java DomesticDivision.java UseDivision.java

Run the application:
  java UseDivision

The program creates two InternationalDivision objects and two DomesticDivision
objects, then displays all four through a Division array. Account numbers use
String values to preserve leading zeros. No external libraries are needed.

Files:
  Division.java - Abstract superclass with required constructor and display().
  InternationalDivision.java - Adds country and language; overrides display().
  DomesticDivision.java - Adds state; overrides display().
  UseDivision.java - Application entry point and four sample instances.
  sample-output.txt - Output captured from a successful execution.
