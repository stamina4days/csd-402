Prince Hubbard - CSD402 Module 4.2

Hubbard_Mod4_2.java contains all four required overloaded average methods
and a main method that tests arrays of lengths 3, 4, 5, and 6.
expected_output.txt contains output captured from a successful Java 17 run.

To compile and run from this folder with a JDK:
    javac Hubbard_Mod4_2.java
    java Hubbard_Mod4_2

Alternatively, with Java 11 or newer:
    java Hubbard_Mod4_2.java

Integer return types truncate fractional results toward zero. The double
method retains a fractional result. Arrays must not be null or empty.
The long method assumes the sum fits within the long range.
